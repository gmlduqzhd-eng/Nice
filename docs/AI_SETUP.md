# 키워드 AI 생성 연결

## 무료로 시작하기

이 앱은 Google Gemini API의 `gemini-3.5-flash-lite`를 직접 호출한다. 2026-09-30 확인한 [공식 요금표](https://ai.google.dev/gemini-api/docs/pricing)에는 이 모델의 무료 입력·출력 이용이 제공된다. [사용량 제한](https://ai.google.dev/gemini-api/docs/rate-limits)은 모델·프로젝트별로 달라지므로 특정 일일 횟수를 앱에서 보증하지 않는다.

1. [Google AI Studio API 키](https://aistudio.google.com/api-keys)에서 본인 계정으로 로그인한다.
2. **Free Tier 프로젝트**를 선택하거나 생성해 API 키를 발급한다. 무료로 시험하려면 프로젝트의 Cloud Billing을 활성화하거나 유료 요금제로 올리지 않는다. 이미 결제가 연결된 프로젝트의 키는 무료 이용을 보증하지 않는다.
3. 키는 채팅이나 소스에 붙이지 않고 아래 서버 환경변수에만 저장한다. Google 로그인의 공개 Client ID와는 다른 값이다.

앱은 유료 모델로 자동 전환하지 않으며 Vercel AI Gateway의 결제수단 등록도 필요하지 않다. 처음 검토한 Gateway는 해당 계정의 카드 미등록으로 요청이 거부됐으므로 최종 구현에서 사용하지 않는다.

## 현재 PC

저장소의 Git 제외 파일 `.env.local`에 아래 항목을 추가한다. 이미 있는 Supabase·Google 로그인 설정을 삭제하지 않는다.

```dotenv
GOOGLE_GENERATIVE_AI_API_KEY=발급받은_키
```

개발 서버를 재시작하면 `http://127.0.0.1:3000`에서 사용할 수 있다. 키 이름 앞에 `NEXT_PUBLIC_`를 붙이지 않는다.

## 운영 사이트

[Vercel nice_helper_ys 환경변수](https://vercel.com/gmlduqzhd-engs-projects/nice_helper_ys/settings/environment-variables)에서 `GOOGLE_GENERATIVE_AI_API_KEY`를 추가하고 Production에 적용한 뒤 재배포한다. 미리보기에도 필요하면 Preview에 별도로 설정한다. 다른 동명 프로젝트 `nice_helper`와 구분한다.

키를 등록하는 작업은 AI 서비스의 이용 조건을 충족하는 계정 소유자가 직접 진행한다. 키가 없거나 공급자에서 거부하면 앱은 ‘AI 연결 설정을 확인해야 합니다’라고 안내하며, 예시 문장을 실제 AI 결과로 대신 표시하지 않는다.

## 이용 흐름

1. 앱에 로그인하고 ‘나이스 입력 준비’를 연다.
2. 문장 칸에 `친구 의견 경청, 모둠 협력, 맡은 역할 책임감`과 같은 가상 키워드를 적는다.
3. 분량을 선택하고, 필요한 경우 선택한 관찰 근거를 함께 반영한다.
4. ‘AI 생성’ 뒤 초안을 읽고 ‘이 문장 적용’을 누른다. 마음에 들지 않으면 취소해 원문을 유지한다.
5. 사실과 관찰 근거를 확인한 뒤 기존 검토·복사 단계를 진행한다. AI가 나이스에 자동 입력하거나 저장하지 않는다.

## 데이터와 제한

- 키워드·선택한 근거·분량만 생성 자료로 전송한다. 브라우저에서 명부에 등록된 이름을 가리지만 임의로 적은 다른 개인정보를 모두 익명화하는 기능은 아니다.
- Gemini 무료 API의 입력·출력은 Google 제품 개선에 사용될 수 있다. 실제 학생 자료 대신 가상 자료로 검증한다. [공식 데이터 사용 조건](https://ai.google.dev/gemini-api/terms)
- 서버에서 Supabase 사용자 세션을 검증한다. 로그인 계정 정보는 AI 프롬프트에 추가하지 않는다. API 키·사용자 토큰·프롬프트를 앱 로그에 남기지 않는다.
- 2~2,000자 키워드, 선택 근거 최대 10건, 요청 본문 64KiB, 완성 출력 1,500 UTF-8 바이트, 서버 처리 제한 30초를 적용한다. 출력 상한은 이 기능의 기준이며 공식 나이스 제한 보증이 아니다.
- 서버 인스턴스마다 계정별 동시 요청 1개·분당 20개 제한을 둔다. 서버 재시작이나 여러 인스턴스를 아우르는 영구 사용량·요금 상한이 아니며, 실제 무료 이용 한도는 Google 프로젝트의 요금제와 할당량으로 관리한다.
- 취소·학생/계정 변경·원문 수정·저장 충돌 후 오래된 결과를 적용하지 않는다. AI 초안에 입력하지 않은 사실이 섞일 수 있으므로 교사가 검토해야 한다.

## 검증 구분

단위/API와 브라우저 테스트는 가상 사용자·모의 생성 응답을 사용한다. Google SDK의 요청·응답 형식도 모의 Google 응답으로 확인한다. API 키 등록 후 실제 모델 호출과 생성 문장 품질을 별도로 확인해야 실제 연결 완료라고 할 수 있다.
