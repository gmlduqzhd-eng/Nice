# 담임노트

초등교사의 관찰 기록, 학기 말 점검, 나이스 입력 준비를 연결하는 웹앱입니다. v0.5.1은 키워드 AI 초안과 교과별 학기말 의견 준비, 화면 연결 점검을 제공합니다. 무료 이용이 가능한 Gemini 모델을 서버에서 직접 호출하며, 사용하려면 Google AI Studio API 키 설정이 필요합니다. 가상 데이터 시제품 범위는 유지하며 실제 나이스 화면 호환성은 아직 미검증입니다.

[배포된 앱](https://nicehelperys.vercel.app) · [공개 GitHub 저장소](https://github.com/gmlduqzhd-eng/Nice) · [배포·수정 안내](docs/DEPLOYMENT.md)

## 현재 사용할 수 있는 기능

- 문장 칸 키워드 → AI 생성 → 미리보기 → 교사 적용. 분량 선택과 선택한 관찰 근거 포함 여부 설정. [무료 Gemini 연결 방법](docs/AI_SETUP.md)
- 새로고침·세션 복구에서는 로그인 완료 알림을 반복하지 않고 실제 로그인 시에만 안내
- 클라우드 저장 직전 다른 기기의 변경 감지, 새로 생성된 백업 덮어쓰기 방지, 복원 대기 중 새 편집 보존
- JSON·클라우드 복원 전 현재/백업 학급·기록 건수 확인, 복원 후 관찰 노트로 바로 이동
- 나이스 작업 도우미: 검토가 끝나고 점검 문제가 없는 학생 선택 → 작업 JSON → 화면의 학급·학생 대조 → 빈 문장 입력칸 채우기
- 학기말 종합의견 준비(검증용): 작업 학년도·학년·반·학기·교과를 별도 선택 → 현재 가상 명부의 학생별 의견 직접 작성 → 학기말 교사 검토 → 선택한 학생의 v2 작업 파일. 기존 행특 문장·검토 상태·AI와 분리
- Chrome·Edge 확장프로그램 다운로드와 `/neis-practice` 가상 연습 화면. 실제 나이스 저장·자동 로그인은 수행하지 않음
- 연습 페이지의 ‘웹 연습 도우미 열기’로 같은 입력 코드를 실행 → 작업 파일 선택 → ‘연습 화면 항목 자동 지정’ → 화면 대조 → 빈칸 입력. 확장프로그램 설치와 실제 나이스 호환성 검증은 별도
- 수동 지정 오류에는 선택한 값·작업 파일 값을 표시. ‘지정한 값 확인’에서 일곱 항목을 점검 가능
- 실제 화면 연결 준비: 작업 파일 없이 입력칸 구조 점검 → 개인정보 없는 연결 점검 JSON 받기. 문장 입력·저장은 실행하지 않으며 실제 호환성은 별도 확인
- 학년도·학년·반·학기 표시 설정, 학생 추가·수정, 기록 없는 학생 삭제
- UTF-8 CSV·TSV 또는 엑셀 두 열 붙여넣기 → 중복 점검 → 미리보기 → 명부 추가, CSV 내려받기
- 계정별 브라우저 기록 분리, 로그인 전 체험 공간 유지, 다른 탭의 변경 감지 시 편집 중지
- v1 백업을 v2로 변환하여 읽기, 이전 로컬 원본 보존

- 가상 학생 8명과 관찰 12건으로 시작하는 업무 대시보드
- 관찰 기록 추가·수정·삭제, 학생·교과·내용 검색
- 시작 화면의 간단한 사용 안내와 ‘저장하고 다음 학생’ 연속 기록
- 빈 문장, 근거 누락, 중복 문장, 다른 학생 이름, 잘못 연결된 근거 점검
- 학생별 관찰 근거 선택 → 원문 모으기 → 교사 편집 → 검토 → 복사 → 반영 확인
- 문장이나 근거 변경 시 검토 상태 자동 초기화
- 브라우저 저장, 최대 20MB JSON 백업·복원, 예시 데이터 초기화. 파일 내보내기·불러오기에 같은 크기 기준 적용(클라우드 백업은 별도 2MB 제한)
- 나이스 학교 검색·월별 학사일정 API 및 연결 오류 안내
- 상단 ‘회원가입 · 로그인’에서 이메일 링크로 가입·로그인 통합, 재전송·이메일 변경·실패 안내
- 앱 시작 시 로그인 반환 처리, 내 계정 화면의 수동 백업과 소유자 전용 RLS
- 서비스 하단 저작권 표기와 저작권 안내

**실제 학생 개인정보를 입력하지 않는 가상 데이터 시제품입니다.** 입력 도우미는 사용자가 지정한 일반 텍스트 입력칸을 채우는 개발 버전이며, 실제 나이스 자동 업무 완료를 보장하지 않습니다. 나이스 로그인·저장 버튼은 실행하지 않고 iframe·캔버스·전용 편집기는 중단합니다. 대상 사이트의 입력 이벤트가 자동 저장을 실행할 가능성은 화면별 검증이 필요합니다. AI 생성은 로그인 후 별도로 누를 때만 키워드와 선택한 근거를 Gemini에 보냅니다. 무료 API는 입력·출력을 제품 개선에 사용할 수 있습니다. 기존 ‘선택한 관찰 원문 모으기’는 AI 호출 없이 동작합니다. 바이트 수는 UTF-8 참고값이며 나이스 입력 제한을 보증하지 않습니다.

입력 도우미 설치·지원 범위는 [확장프로그램 안내](extension/neis-helper/README.md)를 참고하세요. 작업 파일은 생성 시점의 스냅샷으로 24시간 후 만료되며, 원본 문장을 고쳤다면 즉시 새 파일을 받아야 합니다. 도우미의 입력 성공은 기존 초안의 ‘복사됨’·‘반영 확인’ 상태를 바꾸지 않습니다.

학기말 준비에서는 예를 들어 5학년 2학기처럼 작업할 학급·학기와 교과를 현재 기록의 학급 표시와 별도로 선택할 수 있습니다. **학기말 작성 자료는 임시 화면 상태이며 브라우저·클라우드 백업에 저장되지 않습니다.** 작업 종류 탭을 오가는 동안은 유지되지만 다른 메뉴로 이동하거나 새로고침·창 닫기를 하면 사라지므로 작업 파일로 보관하세요. 교과·학급·명부·문장 변경 후에는 다시 검토합니다. 학기말 파일은 `format: damim-neis-job`, `version: 2`, `task: semester-subject-opinion`이며 필수 교과를 포함합니다. 기존 행특 작업 파일(v1)과 백업 데이터(v2)는 별도 형식입니다.

2026-09-30 실제 나이스 학기말 화면에서는 입력칸과 선택 행·열의 **구조만 읽기 전용으로 확인**했습니다. 2026-10-01 사용자 제공 Edge 화면과 개인정보 없는 점검 JSON에서 설치·패널 실행과 마감 안내의 점검 사유를 확인했습니다. 최신 수정본의 사용자 프로필 실행, 실제 나이스 입력·저장·자동 저장 여부는 아직 미검증입니다. 학기말 연결 코드는 하나의 선택된 `role=row`와 정확한 다섯 열(선택, 반/번호, 성명, 참고자료, 학기말종합의견), 같은 행의 번호·이름·의견 셀을 대조합니다. ‘학생부 반별 마감됨’ 안내가 보이면 입력은 중단하지만 화면 대조는 진행할 수 있습니다. 대조 결과가 일치해도 입력 버튼은 활성화하지 않으며 기존 문장 덮어쓰기 차단을 유지합니다. 이 안내만으로 해당 교과 의견을 수정할 수 없다고 단정하지 않습니다. 실제 학생 이름·교사·학교·문장 원문을 소스·테스트·문서·로그로 옮기지 않습니다.

## 선생님의 이용 순서

1. 로그인 없이 시작 안내를 따라 가상 학생의 관찰 기록을 남깁니다. 여러 학생을 기록할 때는 ‘저장하고 다음 학생’을 누르면 날짜·분류를 유지하며 다음 학생으로 넘어갑니다.
2. ‘나이스 입력 준비’에서 근거를 고르고 문장을 다듬은 뒤 검토·복사합니다. AI 연결이 준비됐다면 키워드를 적고 ‘AI 생성’으로 초안을 확인한 뒤 적용할 수 있습니다. 나이스 화면에서 저장한 내용을 직접 확인한 다음 반영 확인을 누릅니다.
3. 기록은 현재 브라우저에 저장됩니다. 필요한 자료는 ‘설정 및 백업’에서 파일로 보관하고, 계정 백업은 로그인 후 직접 저장 버튼을 누릅니다.

**현재 이메일 로그인은 Supabase 조직 팀원 이메일을 사용하는 테스트 계정에 제한됩니다.** 일반 교사 대상 이메일 가입을 열려면 별도 SMTP 연결이 필요합니다. 현재 무료 프로젝트는 기본 메일 템플릿도 수정할 수 없어 인증번호 입력 방식 대신 기본 로그인 링크 방식을 사용합니다. Google은 공개 Client ID를 사용하는 GIS 방식으로 배포했고 Google 앱의 **Production 전환**을 확인했습니다. Client Secret 수동 입력은 필요하지 않습니다. 기본 인증 범위는 추가 데이터 접근 심사가 필요 없으며, 앱 이름·로고 표시용 브랜드 검증은 별도로 진행하지 않았습니다. **2026-09-29 일반 Chrome에서 실제 Google 로그인, 가상 자료 수동 저장과 같은 브라우저의 클라우드 복원을 확인했습니다.** 다른 브라우저의 불러오기 성공 안내는 사용자가 확인했습니다. 해당 브라우저의 복원 원문 직접 대조, 다른 PC 확인, 로그아웃 후 재로그인, 실제 두 계정의 접근 격리와 메일 로그인은 아직 미검증입니다. 이전 Codex 내장 브라우저의 FedCM 오류 관측은 [Google 설정과 남은 검증](docs/GOOGLE_AUTH.md)에 별도로 기록했습니다. [연동 상태와 절차](docs/INTEGRATIONS.md)

## 실행

Node.js 24와 프로젝트에 고정된 pnpm 11.19.0을 사용합니다. 실제 개발·검증도 Node.js 24에서 수행했습니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

브라우저에서 http://127.0.0.1:3000 을 엽니다. 환경변수 없이 가상 데이터 기능을 이용할 수 있습니다.

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

브라우저 검증은 Chrome이 설치된 환경에서 개발 서버를 실행한 뒤 `pnpm test:e2e`로 실행합니다.

설치된 확장 실행 검증만 실행하려면 `pnpm test:e2e e2e/neis-extension.spec.ts`를 사용합니다. 이 검증은 임시 Chrome 프로필에 확장을 로드하고 실제 확장 액션·서비스 워커를 실행합니다. 최신 Chrome의 브라우저 수준 CDP `Extensions.loadUnpacked`·`Extensions.triggerAction` 지원이 필요하며, 154.0.8037.58에서 확인했습니다. 테스트용 디버깅 옵션은 자동 생성·폐기하는 프로필에만 적용합니다. 평소 사용하는 Chrome을 이 옵션으로 실행할 필요는 없습니다. [검증 범위](docs/VERIFICATION.md)

## 나이스·Supabase 연결

`.env.example`을 `.env.local`로 복사하고 필요한 값을 설정한 뒤 서버를 재시작합니다.

| 환경변수 | 용도 |
| --- | --- |
| `NEIS_API_KEY` | 서버에서만 사용하는 나이스 공개 API 인증키 |
| `GOOGLE_GENERATIVE_AI_API_KEY` | 서버 전용 Google AI Studio 키. 무료 사용은 Free Tier 프로젝트로 설정하고 한도 내 이용 |
| `NEXT_PUBLIC_SUPABASE_URL` | 사용할 Supabase 프로젝트 URL |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | `sb_publishable_`로 시작하는 공개 키 |
| `NEXT_PUBLIC_GOOGLE_CLIENT_ID` | GIS용 공개 웹 Client ID. Supabase Google 공급자에 등록한 값과 일치 |
| `NEXT_PUBLIC_GOOGLE_AUTH_ENABLED` | 기본값 `false`. 공급자·origin 설정 후 대상 빌드에서 `true`로 바꾸고 실제 로그인 검증 |

Supabase 비밀 키나 service-role 키는 입력하지 않습니다. Google의 공개 Client ID는 브라우저 앱 식별자이며, Client Secret이나 사용자 토큰을 공개 환경변수에 넣지 않습니다. 구체적인 연결·SQL·인증 URL 설정은 [연동 안내](docs/INTEGRATIONS.md), GIS 설정은 [Google 로그인 안내](docs/GOOGLE_AUTH.md)를 참고하세요.

**2026-09-29 연결 상태:** GitHub `main`을 Vercel `nice_helper_ys`에 연결해 배포했고, Supabase `Nice` 프로젝트의 URL·공개 키 및 인증 반환 주소를 설정했습니다. `supabase/schema.sql`은 대시보드 SQL Editor에서 적용했으며 마이그레이션 이력 파일은 아닙니다. SQL 트랜잭션에서 소유자·타 사용자·익명 접근과 제약조건을 검증했고, 실제 익명 REST 요청의 접근 거부도 확인했습니다. Google 로그인한 계정의 가상 자료 저장·같은 브라우저 복원은 확인했습니다. **이메일 링크 로그인, 독립 브라우저의 복원 내용 직접 대조, 다른 PC 확인과 실제 두 계정의 접근 격리는 아직 미검증입니다.** 나이스 운영 인증키도 미설정입니다. [검증 기록](docs/VERIFICATION.md)

## Vercel 배포 설정

1. 이 프로젝트 폴더를 Git 저장소로 관리하고 원하는 Vercel 프로젝트에 연결합니다.
2. 프레임워크를 Next.js로 설정합니다. Node.js는 `package.json`의 `24.x`를 사용하며, `vercel.json`은 서울 리전 `icn1`을 지정합니다.
3. Vercel 프로젝트의 미리보기·운영 환경변수에 `ENABLE_EXPERIMENTAL_COREPACK=1`을 등록합니다. Corepack이 `package.json`의 `packageManager`에 고정된 pnpm 11.19.0을 사용하도록 하는 필수 빌드 설정입니다. Install Command는 기본 자동 설정을 유지합니다. [Vercel Corepack 설정](https://vercel.com/docs/builds/configure-a-build#corepack)
4. 필요한 앱 환경변수만 개발·미리보기·운영 환경에 구분해 등록합니다.
5. Supabase 로그인 Redirect URLs에 실제 배포 주소를 등록합니다. GIS 로그인은 Google 웹 클라이언트의 Authorized JavaScript origins에 해당 배포의 정확한 origin도 등록합니다.
6. 가상 데이터로 연결을 검증한 미리보기부터 확인합니다.

현재 배포는 기존 Vercel·Supabase 프로젝트를 사용합니다. 이후 `main` 변경은 GitHub 연결을 통해 자동 배포됩니다. 같은 저장소에 연결된 다른 Vercel 프로젝트 `nice_helper`도 있으므로 배포 대상을 구분합니다. 상세 연결 현황과 수정 절차는 [배포 안내](docs/DEPLOYMENT.md)에 기록했습니다. 개인정보 실사용은 학교의 운영·위탁·보유기간·접근권한 조건을 확인한 후 별도 단계로 진행합니다.

## 알려진 범위 제한

- 계정별로 한 학급의 표시와 명부를 관리합니다. 여러 학급 전환·새 학년도 보관·전출 처리는 아직 없습니다. CSV는 현재 명부에 학생을 추가하며 기존 번호를 덮어쓰지 않습니다. 실제 학생 정보는 입력하지 않습니다.
- 학기말 작업의 별도 학급·교과 선택은 임시 파일의 대상을 정하는 기능입니다. 여러 학급·학년도 기록 공간이나 학기말 의견의 지속 저장을 추가하지 않습니다. 가상 학기말 연습은 `/neis-practice?task=semester`에서 진행합니다.
- 출결·증빙 첨부·평가 계획·교사 간 공유는 후속 개발 범위입니다.
- 클라우드는 교사 한 계정의 수동 스냅샷 백업입니다. 학교 조직 권한이나 실시간 공동 편집은 구현하지 않았습니다.
- 로그아웃하면 체험 공간으로 돌아가고 로그인하면 해당 계정 공간을 엽니다. 로그인 전 기록은 자동 이전·업로드하지 않습니다. 필요하면 JSON 백업을 수동으로 옮깁니다. 브라우저 저장은 암호화되지 않으며 원격 접근 제어를 대체하지 않습니다.
- 다른 탭의 저장 이벤트와 쓰기 직전 원본 비교로 충돌을 감지하고 편집을 멈춥니다. 분산 잠금이나 자동 병합은 제공하지 않으므로 한 기록 공간은 한 탭에서 편집하세요. 클라우드 백업도 수동 스냅샷 방식입니다.
- 글꼴은 Google Fonts에서 불러오며 연결이 없으면 시스템 글꼴을 사용합니다.
