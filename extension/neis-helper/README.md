# 담임노트 나이스 입력 도우미 0.5.1

행동특성 및 종합의견과 교과별 학기말 종합의견 입력을 위한 개발·검증용 확장프로그램입니다. 실제 나이스 입력·저장 호환성은 아직 검증하지 않았습니다. 가상 자료만 사용하세요.

0.5.1은 학기말 의견의 학급·교과·선택 행 대조와 개인정보 없는 화면 연결 점검을 포함합니다. 마감 안내가 여러 태그나 줄바꿈 없는 공백으로 나뉘어도 입력을 중단하고, 같은 탭에서 다시 정상 실행하면 이전 오류 표시를 해제합니다. AI 호출은 웹앱에서만 수행하며 확장 권한은 추가하지 않습니다.

기존 설치는 새 파일로 갱신한 뒤 확장 관리 화면의 새로고침 버튼을 누르세요. 이전에 열린 도우미 패널은 닫고 다시 열어 **0.5.1** 표시를 확인합니다.

1. 압축을 풀고 Chrome의 chrome://extensions 또는 Edge의 edge://extensions에서 개발자 모드를 켭니다.
2. ‘압축해제된 확장 프로그램을 로드합니다’로 이 manifest.json이 들어 있는 폴더를 선택합니다.
3. https://nicehelperys.vercel.app 의 ‘나이스 작업 도우미’에서 검토한 학생을 선택해 작업 JSON을 받습니다.
4. https://nicehelperys.vercel.app/neis-practice 를 열고 확장프로그램 아이콘을 클릭합니다. 작업 파일을 연 뒤 일곱 항목을 지정합니다.
5. 학급 표시 값과 **학생별 편집 영역 안의 번호·이름**, ‘행동특성 및 종합의견’ 입력칸을 선택합니다. 목록의 다른 학생을 지정하지 마세요.
6. 화면 대조 → 대조한 빈칸에 입력. 입력 후에는 직접 내용과 저장 결과를 확인하세요. 학생 전환 후에는 다시 대조합니다.

## 학기말 종합의견 작업 준비

1. 웹앱 ‘나이스 작업 도우미’에서 ‘학기말 종합의견’을 선택하고 작업 학년도·학년·반·학기·교과를 확인합니다. 예를 들어 5학년 2학기로 선택해도 기존 관찰 기록의 학급 표시는 바뀌지 않습니다.
2. 현재 가상 명부의 학생별 의견을 직접 작성하고 별도의 학기말 교사 검토 확인을 누릅니다. 행특 문장·검토 상태는 가져오지 않으며 AI를 호출하지 않습니다. 교과·학급·명부·문장을 바꾸면 다시 검토합니다.
3. 검토한 학생을 선택하고 학기말 작업 JSON을 받습니다. `version: 2`, `task: semester-subject-opinion`이며 필수 `subject`를 포함합니다. 기존 행특 파일은 `version: 1`, `task: behavior-opinion`입니다.
4. 가상 연습은 https://nicehelperys.vercel.app/neis-practice?task=semester 또는 로컬 앱의 같은 경로에서 진행합니다.
5. 파일을 연 뒤 학년도·학년·반·학기·교과·학생 번호·학생 이름·문장 입력칸을 지정하고 화면 대조를 진행합니다. 같은 학생의 **선택된 행** 안에서 번호·이름·학기말 의견의 정확한 열을 지정해야 합니다.

**학기말 작성 자료는 임시 화면 상태이며 브라우저·클라우드 백업에 저장되지 않습니다.** 작업 종류 탭 전환 중에는 유지되지만 다른 메뉴 이동·새로고침·창 닫기로 사라집니다. 필요한 문장은 작업 파일로 보관하세요. 파일은 생성 후 24시간 동안만 입력 작업에 사용할 수 있고, 수정 후에는 새 파일을 받습니다.

학기말 연결은 `role=grid`의 다섯 헤더를 확인합니다. 첫 헤더는 ‘선택’ 또는 체크박스가 있는 빈 선택 헤더, 이후 순서는 ‘반/번호’, ‘성명’, ‘참고자료’, ‘학기말종합의견’입니다. 정확히 다섯 셀을 가진 `role=row` 중 `aria-selected=true`인 행이 하나여야 하며, 번호·이름과 일반 문장 입력칸을 해당 행의 올바른 셀에서 대조합니다. 여러 선택 행·다른 열·모호한 구조·기존 문장·수정 불가능한 칸은 중단합니다.

‘학생부 반별 마감됨’ 안내가 보이면 **추가 확인 필요**로 처리해 입력을 중단합니다. 화면 대조는 학급·교과·학생·입력칸 검사를 끝까지 진행할 수 있지만 입력 준비를 만들거나 입력 버튼을 활성화하지 않습니다. 기존 문장이 작업 파일과 다르면 덮어쓰기 차단도 유지합니다. 이 안내만으로 해당 교과 의견을 수정할 수 없다고 단정하지 않습니다. 나이스의 현재 상태와 처리 절차를 교사가 직접 확인하세요.

2026-09-30 실제 학기말 화면은 입력칸·선택 행·열 구성의 구조만 읽기 전용으로 확인했습니다. 최신 확장의 사용자 프로필 설치, 실제 나이스 문장 입력·저장·자동 저장 여부는 아직 미검증입니다. 실제 학생 이름·교사·학교·문장 원문을 소스·테스트·문서·로그로 복사하지 않습니다.

## 실제 화면 연결 점검

작업 파일을 열지 않고 사용할 수 있습니다. 직접 로그인한 나이스의 ‘학급담임 → 학생생활 → 행동특성및종합의견’ 화면에서 도우미를 열고 다음 순서로 점검합니다.

1. ‘화면 연결 점검’으로 최상위 화면에 보이는 일반 입력칸·iframe·캔버스·직접 편집 영역의 개수를 확인합니다. iframe이나 전용 편집기의 내부는 확인하지 않습니다.
2. ‘입력칸 선택해 점검’을 누른 뒤 행특 또는 학기말 입력칸을 클릭합니다. 문장 내용은 읽지 않고 입력칸 종류·활성 상태·라벨 연결·편집 영역의 구조만 확인합니다. 학기말 그리드는 고정된 공개 헤더와 선택 행·의견 셀의 연결도 점검합니다. Esc로 선택을 취소할 수 있습니다.
3. ‘연결 점검 파일 받기’를 누릅니다. 선택한 입력칸이 사라지거나 변경되었다면 최신 구조를 다시 점검한 결과를 받습니다.

‘추가 확인 필요’이면 패널에 구체적인 점검 사유와 조치를 함께 표시합니다. 마감 안내·수정 불가 상태·학생 행 선택·라벨 연결·편집 영역 등의 기존 고정 점검 코드만 설명하며 학생 값이나 화면 원문을 표시하지 않습니다. 입력칸을 새로 선택하거나 다시 점검하면 이전 사유 목록을 갱신합니다.

파일에는 고정된 버전·화면 종류·요소 개수·구조 불리언·원인 코드만 들어갑니다. **학생/학급 값·문장·작업 파일·주소·DOM·셀렉터·속성/라벨 원문·오류 메시지는 포함하지 않습니다.** 연결 점검은 입력칸 값을 바꾸거나 입력 이벤트·저장을 실행하지 않습니다.

‘일반 입력칸 후보’는 구조 확인 결과이며 행특·학기말 입력·저장 호환성을 보장하지 않습니다. 번호·이름 대조, 작업 종류·교과 표시와 저장 흐름은 별도로 확인해야 합니다. 점검으로 입력 버튼이 활성화되지는 않습니다. 실제 나이스 호환성 확인이 끝나기 전에는 문장 입력에 가상 자료만 사용하세요.

현재 PC에서 개발 중인 기능입니다. 운영 앱에서 받는 이전 ZIP에는 포함되지 않을 수 있으므로 로컬 앱의 ZIP 또는 이 소스 폴더를 사용하세요. 소스가 갱신되면 확장 관리 화면에서 새로고침하고 대상 페이지도 새로고침합니다.

## 0.4.1의 지정 오류 개선

- 가상 연습 페이지에서는 ‘연습 화면 항목 자동 지정’으로 작업 종류에 맞는 항목을 연결할 수 있습니다. 실제 나이스 주소에서는 이 버튼을 제공하지 않습니다. 자동 지정 후에도 작업 파일의 값과 대조하며, 다른 학생·기존 문장·바뀐 화면을 계속 차단합니다.
- ‘지정한 값 확인’에 선택한 값과 작업 파일 값을 함께 표시합니다. 잘못 클릭한 경우 오류 메시지에서도 두 값을 확인할 수 있습니다. 값은 화면에만 표시하고 외부로 전송하거나 저장하지 않습니다.
- 연습 페이지의 ‘웹 연습 도우미 열기’는 같은 core.js/content.js를 웹에서 실행합니다. 확장프로그램 설치·권한 동작 검증과는 다릅니다. 패널의 ‘웹 연습’ 표시를 확인하세요.
- 0.4.0을 설치했다면 새 ZIP의 파일로 설치 폴더를 갱신한 뒤 확장프로그램 관리 화면에서 새로고침하고, 열려 있던 연습 페이지도 새로고침하세요. 웹 연습은 웹앱 배포 후 페이지 새로고침만으로 갱신됩니다.

## 지원 범위

2026-09-29 Chrome 154.0.8037.58의 별도 임시 프로필에 이 확장을 실제 로드하여 실행 액션 → 서비스 워커 → 작업 파일 읽기 → 가상 연습 화면 대조·입력까지 확인했습니다. 다른 학생·기존 문장 차단, 닫기 후 파일 초기화, 선택한 탭에서만 실행, 새로고침 후 자동 실행하지 않음도 확인했습니다. 브라우저 수준 CDP로 실행 액션을 호출한 자동 검증이며, 사용자 프로필의 도구 모음 수동 클릭·Edge·실제 나이스 화면은 별도 확인 대상입니다.

- 클릭한 탭에서만 activeTab/scripting 권한 사용. 자동 로그인, 인증서·비밀번호 접근, 외부 전송, 브라우저 영구 저장, 비공개 API 호출 없음.
- HTTPS의 *.neis.go.kr, 위 운영 연습 주소, localhost/127.0.0.1의 /neis-practice에서만 실행됩니다. 이 도메인 허용은 호환성 검증 완료를 뜻하지 않습니다.
- 이름이 표시된 일반 HTML 텍스트 입력칸만 지원합니다. 행특의 학생 번호·이름은 같은 form/role=dialog/검증용 편집 영역 안에 있어야 합니다. 학기말은 위 다섯 열과 하나의 선택 행 계약을 따릅니다. 편집 영역의 쓰기 가능한 문장 입력칸은 하나여야 하며 iframe·캔버스·전용 편집기는 지원하지 않습니다.
- 학년도·학년·반·학기·학생 번호·이름이 일치해야 하며 학기말은 교과도 일치해야 합니다. 화면이 바뀌거나 입력칸이 기존 문장으로 차 있으면 중단합니다. 내용이 이미 같아도 저장 성공으로 처리하지 않습니다.
- 입력은 DOM input 이벤트를 사용합니다. 저장 버튼·Enter·submit은 실행하지 않지만 **대상 사이트의 input 이벤트가 자동 저장을 실행할 가능성**은 실제 화면별 확인이 필요합니다.
- 작업 파일은 1MB 이하, 최대 500명, 문장 6,000자 이하이며 24시간 후 만료됩니다. 원본을 수정하면 기존 작업 파일은 폐기하고 새 파일을 내려받으세요. 오프라인 파일은 원본 변경을 자동 감지하지 못합니다.
- 파일에는 선택한 학생의 번호·이름·문장이 들어갑니다. 파일을 외부에 공유하지 마세요. 닫기·새로고침으로 확장프로그램 메모리의 파일·지정을 제거합니다. 다운로드 파일은 별도로 관리해야 합니다.

공식 크롬 API 근거: https://developer.chrome.com/docs/extensions/develop/concepts/activeTab , https://developer.chrome.com/docs/extensions/reference/api/scripting
